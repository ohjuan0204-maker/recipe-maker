# 용액 레시피 메이커

칭량·희석 계산과 한글 라벨을 한 번에.

공개 주소: https://ohjuan0204-maker.github.io/recipe-maker/

## 1분 체험

1. 공개 주소를 엽니다(로그인 없음).
2. 홈의 [1분 체험]을 누르고 [다음]으로 7단계를 봅니다.
3. 마지막 단계에 "체험 완료 코드"(1004)가 보입니다.

---

시약과 목표 농도·부피를 넣으면 칭량 질량(수화물·순도 보정)과 희석 계열의 원액·증류수 부피, 권장 원액 조제량을 계산해 단계별 레시피 카드와 인쇄용 한글 라벨로 만들어 주는 정적 웹앱입니다. 빌드 단계가 없고, 이 폴더 그대로가 사이트입니다.

- 2026 루프랩 랄프톤 출품작 (Lab Hack 트랙)

## 1분 체험의 7단계

`app.js`의 `TOUR` 순서입니다. 단계마다 볼 곳에 테두리를 두르고, Esc로 그만둡니다.

1. 샘플로 칭량 질량 계산 — [샘플: 총괄성 실험]의 고체 넷을 불러와 조제 목록을 비춥니다.
2. 수화물 보정 — MgCl2·6H2O 행의 "수화물 보정됨" 배지.
3. 원액 하나로 여러 농도 — [샘플: 흡광도 실험]을 불러와 희석표를 비춥니다. 메틸렌 블루 100 mg/L 원액 하나로 0.5·1·2·4 mg/L(각 50 mL)를 만듭니다. 원액 0.25 / 0.50 / 1.00 / 2.00 mL.
4. 권장 원액 조제량 — 원액 총 사용량 3.75 mL, 권장 원액 조제량 10 mL.
5. 레시피 카드.
6. 한글 라벨 — 라벨 미리보기를 엽니다(인쇄 창은 열지 않습니다).
7. 체험 끝 — 체험 완료 코드 1004.

| 샘플 두 가지 | 머리의 [샘플: 총괄성 실험]은 고체 넷만 조제 목록에 불러오고 희석 탭은 건드리지 않습니다. [샘플: 흡광도 실험]은 조제 목록을 그대로 두고 희석표만 채웁니다(메틸렌 블루, 원액 100 mg/L → 0.5·1·2·4 mg/L × 각 50 mL). 너비 700px 아래에서는 머리의 흡광도 버튼이 숨고, 희석 탭 [행 추가] 옆의 같은 버튼을 씁니다 |

| 희석 | 원액 농도와 목표 농도·부피(8행까지)로 원액 부피와 증류수 부피, 원액 총 사용량, 권장 원액 조제량을 계산합니다. 용액 이름에 "메틸렌 블루"가 있으면 희석표 아래에 예상 흡광도 줄이 나옵니다(A = 74000 × mg/L ÷ 1000 ÷ 319.85, ε 7.4×10⁴ L/(mol·cm), 무수물 기준, 1 cm 셀 가정. 1.0을 넘는 칸에는 "더 묽게" 안내). 단위가 mg/L이고 원액이 1000 mg/L보다 묽으며 원액에 드는 시약이 0.1 g 미만이면 원액 조제 안내가 한 줄 나옵니다(흡광도 샘플: "10.00 mL를 100 mL로"). 아래에는 같은 배수로 거듭 묽히는 연속 희석 계산이 있습니다 |

| 이론값 계산 | 실험을 고르고 넣을 양을 적으면 이론대로일 때 나와야 할 값과 풀이 과정이 나옵니다. 실험 20개. 실제로 잰 값을 넣으면 오차율을 알려 줍니다. 문헌값(중화열, Ksp 등)은 교재의 값으로 고칠 수 있습니다. 중화열·용해열도 절대영도 이하 온도를 막습니다 |

## 라이선스와 출처

화면에는 출처를 적지 않습니다. 값의 출처는 이 README와 코드의 주석에만 둡니다(이 프로젝트의 규칙).

- 글꼴: Noto Sans KR, Inter — SIL Open Font License 1.1 (`fonts/LICENSE.txt`).
- 기본 시약 12종의 몰질량: 팀의 제작 계획서.
- 시약표: 학교 화학실험실 시약 목록(2025. 3. 1. 현재)에서 시약명·한글명·화학식·분자량만 옮겼습니다. 보관 위치는 넣지 않았습니다. 분자량은 화학식으로 다시 계산해 확인했고, 맞지 않는 행은 다시 계산한 값을 씁니다.
- 시약표의 PubChem 정보: PubChem(미국 국립 의학 도서관 NCBI)의 PUG REST로 2026. 11. 16.에 받은 화합물 번호, 화학식, 분자량, GHS 분류. GHS는 참고용이며 병의 라벨과 학교 MSDS가 우선입니다.
- 진한 산·염기의 함량과 밀도: OpenStax Chemistry 2e 부록 F의 대표값.
- 용매의 Kf · Kb · 어는점 · 끓는점: OpenStax Chemistry 2e 표 11.2.
- 약산·약염기의 이온화 상수: OpenStax Chemistry 2e 부록 H·I.
- 메틸렌 블루의 몰 흡광 계수 7.4×10⁴ L/(mol·cm)와 몰질량 319.85: 2차 런 프롬프트에 적힌 값(`calc.js`의 `ABSORB`). 문헌 출처는 확인 전입니다.
- 폐액 나누기: 과학실험 안전 매뉴얼(고등학교, 한국과학창의재단 2021) 4-4.
- R&E 주제와 실험의 글: 이 앱을 위해 새로 정리했습니다. 실제 실험은 선생님의 지도와 학교의 안전 수칙을 따르세요.
- 화면의 배치: 실험 자료 사이트들이 흔히 쓰는 틀을 따랐고, 다른 사이트의 로고·문구·이미지는 쓰지 않았습니다.
