# 용액 레시피 메이커

칭량·희석 계산과 한글 라벨을 한 번에.

시약과 목표 농도·부피를 넣으면 칭량 질량(수화물·순도 보정)과 희석 계열의 원액·증류수 부피, 권장 원액 조제량을 계산해 단계별 레시피 카드와 인쇄용 한글 라벨로 만들어 주는 웹앱입니다.

- 공개 주소: 미정 (GitHub Pages에 올린 뒤 채웁니다)
- 2026 루프랩 랄프톤 출품작 (Lab Hack 트랙)

## 1분 체험

1. 페이지를 엽니다. 홈 화면이 보입니다.
2. [샘플: 총괄성 실험]을 누릅니다.
3. 조제 목록의 MgCl2·6H2O 행에서 "수화물 보정됨" 배지를 확인합니다.
4. 희석 탭에서 원액 1000 mg/L로 계산된 4개 농도를 봅니다.
5. 권장 원액 조제량(10 mL)을 확인합니다.
6. 레시피·라벨 탭에서 레시피 카드를 봅니다.
7. [라벨 인쇄]를 눌러 라벨 미리보기를 엽니다.
8. 미리보기 아래에 체험 완료 코드가 나타납니다.

## 기능

| 화면 | 하는 일 |
|---|---|
| 고체 조제 | 기본 시약 12종, 시약표의 시약, 직접 입력. 단위 M · mM · mg/L · % (w/v), 순도 50~100%. 칭량 질량을 g 단위 소수 셋째 자리로 보여 주고 조제 목록에 12행까지 쌓습니다 |
| 액체 시약 | 진한 산·염기처럼 함량(%)과 밀도로 파는 시약. 원액의 몰 농도와 취할 부피를 계산합니다. 염산·황산·질산·아세트산·인산·암모니아수는 대표값이 들어 있고 병 라벨의 값으로 고쳐 쓸 수 있습니다 |
| 희석 | 원액 농도와 목표 농도·부피(8행까지)로 원액 부피와 증류수 부피, 원액 총 사용량, 권장 원액 조제량을 계산합니다. 아래에는 같은 배수로 거듭 묽히는 연속 희석 계산이 있습니다 |
| 계산 도구 | 계산 29가지를 왼쪽에 묶음별로 늘어놓고, 고른 계산 하나를 오른쪽에서 합니다. 위의 찾기 칸에 "희석", "pH"처럼 치면 맞는 계산만 남고(틀린 글자도 알아들음), 엔터로 첫 계산을 엽니다. 숫자 칸은 음수와 1.8e-5, 1.8×10^-5 같은 지수도 읽습니다. 위쪽에 묶음, 식, 이 계산을 쓰는 실험이 나옵니다. 기본 계산 여섯(농도 환산, 중화 적정, 총괄성, 강산·강염기의 pH, 가진 시약으로 만들 수 있는 부피, 농도가 다른 두 용액 섞기)과 실험 계산 모음 23가지 |
| 이론값 계산 | 실험을 고르고 넣을 양을 적으면 이론대로일 때 나와야 할 값과 풀이 과정이 나옵니다. 실험 20개. 실제로 잰 값을 넣으면 오차율을 알려 줍니다. 문헌값(중화열, Ksp 등)은 교재의 값으로 고칠 수 있습니다 |
| 적정 곡선 | 적정의 종류 넷(강산 ← 강염기, 약산 ← 강염기, 강염기 ← 강산, 약염기 ← 강산)과 농도·부피·지시약을 넣으면 넣은 부피에 따른 pH 곡선을 그립니다. 당량점, 반당량점, 지시약의 변색 범위가 그림에 나오고, 넣은 부피를 옮기면 그때의 pH와 지시약의 색을 보여 줍니다. 고른 지시약이 맞는지와 알맞은 지시약도 알려 줍니다 |
| 결과 정리 | 여러 번 잰 값(8회까지)을 넣으면 평균, 표준 편차, 오차율을 정리해 종이 한 장으로 보여 줍니다. 인쇄하거나 글로 복사할 수 있고, 비워 두면 손으로 적을 빈 표가 됩니다. 이론값이 없는 실험은 "직접 넣기"로 씁니다. 엑셀·CSV·한글·워드 파일의 표를 넣으면 회차 칸을 채우거나(반복 측정) 그래프를 그립니다(연속 자료). 반응 시간을 재는 초시계가 있습니다. [실험 보고서]로 바꾸면 목적·이론·준비물·시약·과정·결과·분석·고찰·결론·참고 자료가 채워진 보고서가 나오고, 학교 보고서 양식(.hwpx·.docx)을 넣으면 그 항목 차례를 따릅니다 |
| 오차 분석 | 결과 정리에 넣은 값으로 정확도(오차율과 날 수 있는 폭)와 정밀도(상대 표준 편차), 튀는 값(Q 검정, [값 빼고 보기]), 기구 불확도 표(기구마다 허용 오차, 가장 큰 몫), 실험마다 흔한 오차의 원인과 방향(크게·작게)을 보여 줍니다. 고른 원인은 보고서의 고찰에 들어갑니다 |
| 실험 계획서 | 실험을 고르면 목적, 이론적 배경, 가설, 변인, 준비물, 시약 양(조 수만큼), 과정, 예상 결과, 기록표, 안전, 폐액이 채워진 초안이 나옵니다. 종이에서 바로 고치고, 인쇄하거나 글로 복사하거나 이 브라우저에 보관합니다. 학교 양식(.hwpx·.docx)을 넣으면 그 항목 차례를 따르고 이미 적힌 글은 그대로 둡니다 |
| 폐액 버리기 | 무엇이 섞였는지 고르거나 짧게 적으면(예: 산이 조금 들어간 얼음물) 버릴 통과 까닭, 주의, 붓는 법을 알려 줍니다. 실험 상세와 준비표에도 실험마다의 폐액이 나옵니다. 과학실의 안내가 먼저입니다. 시약표의 시약 이름(옛 이름·새 이름, 영어 이름, 화학식)을 적어도 알아듣고 "시약표에서 찾은 시약" 칩으로 보여 줍니다 |
| 검색 | 주 메뉴 옆의 돋보기. 한 번 친 말로 실험, 계산 도구, 준비물, 화면, 시약표를 함께 찾습니다. "산염기"처럼 붙여 쓴 말, 같은 뜻의 말과 화학식(메스플라스크, HCl, 소금), 초성(ㅈㅎㅈㅈ), 틀린 글자(뷰랫)를 알아듣고, 무엇으로 알아들었는지 알려 줍니다 |
| 시약표 | 시약 467종(학교 시약표 427종 + 자주 쓰는 시약 40종)을 한글명·영문명·화학식으로 찾아 고체 조제나 액체 시약 계산으로 보냅니다. 꼭 맞는 것이 맨 위에 옵니다. 시약마다 GHS 신호어와 그림 문자 이름(부식성, 급성 독성 등)을 보여 줍니다 |
| 1분 체험 | 홈의 큰 그림 아래 [1분 체험]이나 할 일 버튼 아래 [1분 체험 시작]을 누르면 샘플로 칭량 질량 → 수화물 보정 → 희석 → 권장 원액 조제량 → 레시피 카드 → 한글 라벨 → 체험 완료 코드를 7단계로 보여 줍니다. 단계마다 볼 곳에 테두리를 두르고, Esc로 그만둡니다 |

입력은 스스로 저장하지 않습니다. 새로 고침하면 처음 상태로 돌아갑니다. 샘플의 값은 가상입니다. 브라우저에 기억하는 것은 고른 화면 색과, [이 브라우저에 보관]을 눌러 넣어 둔 조제 목록뿐입니다(용액의 이름과 농도, 부피. 조제자 이름은 넣지 않습니다). 공유 링크에는 같은 값이 주소 뒤에 들어갑니다. 서버로 보내는 것은 없습니다.

"취급 주의"는 일부 시약에만 붙습니다. 어떤 시약이든 쓰기 전에 MSDS를 확인하세요.

## 데이터의 출처

화면에는 출처를 적지 않습니다(팀의 요청, SPEC 18장). 값의 출처는 여기와 코드의 주석에만 있습니다.

- 기본 시약 12종의 몰질량: 팀의 제작 계획서.
- 시약표: 학교 화학실험실 시약 목록(2025. 3. 1. 현재)에서 시약명·한글명·화학식·분자량만 옮겼습니다. 보관 위치는 넣지 않았습니다. 분자량은 화학식으로 다시 계산해 확인했고, 맞지 않는 행은 다시 계산한 값을 씁니다 (화면에 표시됩니다).
- 시약표의 PubChem 정보: PubChem(미국 국립 의학 도서관 NCBI)의 PUG REST로 2026. 11. 16.에 받은 화합물 번호, 화학식, 분자량, GHS 분류(ECHA C&L 신고 요약에서 절반 넘게 나온 H 문구 기준). 화학식이 비었던 10종을 채우고 1종(에리오크롬 시아닌 R)을 고쳤으며, 자주 쓰는 시약 40종을 더했습니다. GHS는 참고용이며 병의 라벨과 학교 MSDS가 우선입니다.
- 진한 산·염기의 함량과 밀도: OpenStax Chemistry 2e 부록 F의 대표값.
- 용매의 Kf · Kb · 어는점 · 끓는점: OpenStax Chemistry 2e 표 11.2.
- 약산·약염기의 이온화 상수: OpenStax Chemistry 2e 부록 H·I.
- R&E 주제: 고등학교 실험실에서 할 수 있는 탐구를 이 앱을 위해 새로 정리했습니다. 수상작이나 논문을 옮긴 것이 아닙니다.
- 새로 조합한 주제: 미리 골라 둔 재료와 변인의 조합이고 실험 방안은 틀에 채운 초안입니다. 해 볼 만한지와 안전은 선생님과 검토하세요.
- 화면의 배치: 실험 자료 사이트들이 흔히 쓰는 틀(위쪽 메뉴와 검색, 소개 영역, 왼쪽 찾기와 카드 목록)을 따랐고, 다른 사이트의 로고·문구·이미지는 쓰지 않았습니다.
- 실험의 글: 일반화학의 대표 실험을 이 앱을 위해 새로 썼습니다. 실제 실험은 선생님의 지도와 학교의 안전 수칙을 따르세요.

## GitHub Pages로 배포

1. GitHub에 공개 저장소를 만들고 이 폴더의 파일을 main 브랜치 최상위에 올립니다.
2. 저장소의 Settings → Pages에서 Source를 "Deploy from a branch", Branch를 `main` / `/ (root)`로 고릅니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/`가 열리는지 로그인하지 않은 시크릿 창에서 확인합니다.
4. 열린 주소를 이 파일 맨 위와 SPEC.md 8장에 적습니다.

올리기 전에 PROGRESS.md "남은 일"의 첫 줄(시약표를 공개해도 되는지)을 확인하세요.

- 화면은 좁은 기기(너비 640px 이하)에서 아래 탭 바가 붙는 앱 모양이 됩니다. 시작할 때는 홈만 그리고 다른 화면은 처음 열 때 그립니다(SPEC 23장).

## 바꿀 곳

- 체험 완료 코드: `app.js` 위쪽의 `COMPLETION_CODE = '미정'` 한 줄
- 검색이 알아듣는 말 늘리기: `search.js`의 `SYNONYMS`에 `{ keys: ['친 말'], same: ['앱에 적힌 말'], near: [] }` 한 줄
- 이론값 계산의 처음 값과 문헌값: `theory.js`의 실험마다 `inputs`의 `value`
- 화면 색: `style.css`의 `:root[data-accent="…"]` 묶음(라이트)과 `:root[data-theme="dark"][data-accent="…"]` 묶음(다크). 색을 더하려면 `app.js`의 `ACCENTS`에도 한 줄
- 폐액 통의 이름과 나누는 법: `waste.js`의 `BINS`, `PARTS`, `LAB_NOTES`. 학교의 통 이름이 다르면 여기를 고칩니다
- 계획서의 목적과 변인: `plan.js`의 `LAB_PLAN`. 양식의 항목 이름을 더 알아듣게 하려면 `SECTIONS`의 `keys`
- 라이트의 밝기: `style.css` 끝의 "SPEC 24장" 묶음의 `--bg`, `--surface`
- 준비물: `experiments.js`의 `EQUIPMENT`. `always: true`를 달면 모든 실험의 기본 준비물이 됩니다. 사용법은 같은 파일의 `HOW`
- 오차 분석: 기구의 허용 오차는 `error.js`의 `TOOLS`(A급 기준), 실험마다의 오차 원인과 방향은 `CAUSES`, 불확도 표의 기본 줄은 `BUDGETS`
- 실험 탭(라이트)의 상자 색: `style.css` 끝의 "SPEC 25" 묶음
- 적정 곡선의 처음 값과 이온화 상수: `curve.js`의 `KINDS`와 `index.html`의 `cu-` 칸
- R&E 주제 추천 화면 켜기: `app.js` 위쪽의 `TOPIC_MENU = false`를 `true`로
- 배너가 넘어가는 간격: `app.js`의 `SLIDE_MS` (밀리초). 배너의 장은 `index.html`의 `.slide`
- 기본 시약과 샘플 값, 대표값, 용매 상수, 화면 문구: `calc.js`의 `REAGENTS`, `SAMPLE`, `LIQUID_PRESETS`, `SOLVENTS`, `TEXT`
- 시약표의 시약: `reagents.js`
- 화면의 글을 바꿨는데 `node --test`의 글꼴 검사(A56)가 실패하면, 글꼴에 없는 글자가 생긴 것입니다. `python3 tools/build_fonts.py`로 글꼴을 다시 만듭니다(fontTools와 원본 글꼴이 필요합니다. woff2는 파이썬 brotli 모듈이나 Node.js가 있으면 함께 만들어집니다). 다시 만들 수 없으면 그 글자만 기기의 글꼴로 보이고 나머지는 그대로 동작합니다
